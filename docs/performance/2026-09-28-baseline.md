Accepted as the current diagnostic baseline on 2026-09-28, before the standalone streaming experiment. The figures are preserved from the completed investigation, not remeasured or relabeled as an uninstrumented benchmark.

Capture and preparation overlap. Writes went to a drained PTY, not a rendered terminal. These four 10-second windows had diagnostic tracing enabled. Additional 30-second Kitty CPU/timeline runs without browser tracing delivered 15.50 / 9.97 writes/s at 720p / 4K. The existing 24 FPS ceiling and adaptive pacing remained enabled in Termium.

- Host: ea, native Linux, Ryzen AI 9 HX 370. Measured Chromium reported software compositing/rasterization and SwiftShader.
- Source: runtime base `2beb236`, bounded diagnostics committed as `3d7ca24`, findings committed as `86398e2`. Exact client binary and all retained raw result/profile hashes are in [the baseline manifest](2026-09-28-baseline-manifest.json).
