# Termium v0.2.2

This patch release improves recovery from screenshot errors and cleans up owned
browser processes when a terminal closes.

- Retry an inactive-page screenshot error once on a fresh capture session.
  Persistent failures remain visible; input is never replayed.
- Handle terminal hangup through normal shutdown, stopping the owned server and
  browser. Regression tests exercise both SIGHUP and closing the terminal PTY.
- Include the lock path in installer contention errors and distinguish those
  from other locking failures. The demo rig's earlier unexplained busy-lock
  incident remains unresolved; this release improves its diagnostics.
- Document xterm's tested Sixel configuration and installer-lock troubleshooting.

The demo rig retracted its earlier keyboard-loss diagnosis: its virtual-keyboard
injection was dropping keys before Termium received them. Input diagnostics
remain available. See [the corrected findings](../demo-triage.md).

## Install or update

Close existing Termium sessions, then run:

```sh
curl -fsSL https://termium.dev/install | bash
termium --version
```

The installed command should report `v0.2.2`. Packages support Linux x86-64
(including WSL2), macOS Apple Silicon, and macOS Intel. Native Windows builds,
dark-mode selection, and the experimental CEF backend are not part of this release.
