# Termium v0.2.3

Graphics auto-detection now allows one second per Kitty or Sixel probe instead
of 200 milliseconds. This gives terminals more time to respond during startup,
addressing a suspected cause of ASCII fallback on the installer-launched first
session in Ghostty on macOS. Confirmation on the affected Mac is still needed.

Detection returns immediately when a response arrives. A terminal that does not
answer either probe can take up to two seconds before falling back to ASCII
graphics. Explicit renderer selection is unchanged.

Close Termium, then update:

```sh
curl -fsSL https://termium.dev/install | bash
```

Check the installed release:

```sh
termium --version
```
