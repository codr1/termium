# Website fonts

Unmodified upstream WOFF2 variable fonts, served locally by the website and
included in the offline welcome page. No third-party font service is required.
Both fonts use the SIL Open Font License; the accompanying license files retain
their copyright notices. The application remains MIT-licensed.

- JetBrains Mono: `fonts/webfonts/JetBrainsMono[wght].woff2` from
  https://github.com/JetBrains/JetBrainsMono/tree/19371302b95d218af43299bce79ddbddd0bc364d
  (saved as `JetBrainsMono.woff2`), with `OFL.txt`.
- Inter: `docs/font-files/InterVariable.woff2` from
  https://github.com/rsms/inter/tree/353b61b9f4430d5f420d56605a6e7993e0941470
  (saved as `Inter.woff2`), with `LICENSE.txt`.
