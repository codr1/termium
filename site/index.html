A FEW GOOD QUESTIONS

Before you jump in.

Is this a text-mode browser?

Termium renders Chromium’s screenshots using terminal graphics. Websites keep their visual layout and JavaScript. Without Kitty or sixel support, ASCII graphics approximate the same page using colored blocks. This is a visual fallback, not a text extraction or screen-reader view.

Do I need to install Chromium or Vimium?

The installer supplies the private runtime and automatically downloads Chromium and Vimium. There are no extensions to configure. One command installs everything and opens the browser.

Can I use my mouse?

Yes: click, drag, scroll, and use right or middle buttons. For mouse keys, press F6, move with arrows, then use Enter to left-click, r to right-click, or m to middle-click. Space holds/releases the left button for dragging. See the mouse keys controls.

What about Windows?

Native Windows support comes after Linux and macOS. WSL2 can run the Linux build; terminal graphics support and native Windows application support are separate things.

Will my tabs survive a restart?

Not yet. Tabs keep their state during a session, but profiles and tabs are not persisted after quitting. See the current limits before using Termium for a workflow that depends on session recovery.
